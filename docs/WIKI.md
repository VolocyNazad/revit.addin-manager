# Руководство пользователя

Revit.AddinManager управляет файлами `.addin` до запуска Autodesk Revit. Программа показывает плагины для Revit 2021–2027, позволяет временно отключать их и редактировать манифесты.

## Установка и запуск

Скачайте `RevitAddinManager-<версия>.msi` со страницы релиза GitHub и установите MSI. Установка выполняется для компьютера и создаёт ярлык в меню «Пуск». Запустите Revit.AddinManager до запуска Revit.

Программа работает в Windows и требует .NET SDK только при сборке из исходников; для установленного MSI дополнительные компоненты не нужны.

## Список плагинов

Каждая строка соответствует одному `.addin`-файлу. В списке можно искать по имени файла, фильтровать по версии Revit и области установки (`User` или `Machine`), сортировать по имени, области или версии и группировать строки.

Карточка строки показывает полный путь, типы записей, поставщика и краткие сведения о записях. Кнопка обновления перечитывает диск. Изменения, сделанные в Проводнике или другой копии программы, подхватываются автоматически.

Переключатель строки перемещает файл между корнем каталога версии и его папкой `disabled`: включённый файл загружается Revit, отключённый — нет. Переключение действует сразу и распространяется на все записи внутри файла.

Каталоги имеют стандартный вид:

```text
%APPDATA%\Autodesk\Revit\Addins\<версия>\
%PROGRAMDATA%\Autodesk\Revit\Addins\<версия>\
```

Жёлтый значок предупреждения означает, что в файле нет записей, заполнены не все обязательные поля, указан неизвестный тип или найден повторяющийся `AddInId`. Наведите указатель на строку, чтобы увидеть причины.

Кнопка `+` создаёт пустой `.addin`-файл. Кнопка удаления удаляет файл после подтверждения и восстановить его средствами программы нельзя.

## Редактирование манифеста

Выберите файл и откройте редактор. Доступны четыре режима:

- **Entries** — список записей `<AddIn>` и поиск по имени, типу, поставщику, `AddInId`, `Assembly` и `FullClassName`;
- **Form** — редактирование полей выбранной записи;
- **Markup** — исходный XML с подсветкой, номерами строк и отменой изменений;
- **Settings** — параметры `ManifestSettings` для файла.

Обязательные поля записи — `Assembly`, `AddInId` и `FullClassName`. `AddInId` должен быть корректным GUID и не должен повторяться в файлах одной версии Revit. Ошибки подсвечиваются до сохранения.

Сохранение выполняется атомарно; рядом сохраняется резервная копия `.bak`. Если передумали, нажмите `Discard` в режиме Markup. Добавление и удаление записей требуют подтверждения или выполняются сразу после команды добавления.

Параметр `ManifestSettings` поддерживается только в Revit 2026 и новее. В старых версиях панель доступна для просмотра, но запись заблокирована.

## Ограничения безопасности

Пока запущен любой `Revit.exe`, программа блокирует переключение, создание, удаление и сохранение файлов. Поиск, фильтры, просмотр и смена темы остаются доступны. После закрытия Revit изменения снова разрешены; перезапустите Revit, чтобы он прочитал обновлённые манифесты.

Для файлов области `Machine` Windows может потребовать права администратора. При отказе доступа переключатель возвращается в прежнее положение, а причина показывается под строкой.

## Внешний вид и язык

В панели инструментов можно выбрать тему `System`, `Light` или `Dark`, а также язык интерфейса `System`, `Russian` или `English`. Настройки сохраняются между запусками. Имена XML-полей остаются на английском, поскольку должны совпадать с тегами манифеста.

## Диагностика и помощь

Рабочие журналы находятся в `%APPDATA%\Volocy\Revit.AddinManager\logs\`. Для сообщения об ошибке приложите актуальный журнал, версию приложения, версию Revit и путь к проблемному файлу, предварительно удалив секретные данные.

Кнопка проверки обновлений открывает страницу нового релиза, если он найден. Кнопка поддержки открывает трекер [GitHub Issues](https://github.com/VolocyNazad/revit.addin-manager/issues).

Дополнительные сведения для разработчиков находятся в [руководстве репозитория](repository.md), а полный список реализованных возможностей — в [FEATURES.md](FEATURES.md).
